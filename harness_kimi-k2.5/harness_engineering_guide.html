马与马具的隐喻

Harness 的命名来源

"Harness" 一词源自马具装备——缰绳、马鞍、马衔——用于引导强大但不可预测的动物朝正确方向前进的全套装备。这个隐喻是刻意的：

  • 马 AI 模型——强大、快速，但自己不知道往哪里去
  • 具 Harness 基础设施——约束、护栏、反馈循环，引导模型的力量 productive
  • 手 人类工程师——提供方向，而不是亲自奔跑

关键模式与实践

渐进式披露

Agent 从一个稳定的小切入点开始，被引导去哪里查看，而不是被淹没在 1000 页的说明书中。

Ralph Wiggum 循环

使用 hooks 或中间件强制 Agent 在退出时继续执行验证，防止过早结束任务。

推理三明治

在规划和验证阶段使用高推理预算 (xhigh)，在实现阶段使用中等级别 (high)，在时间预算内获得最佳质量。

垃圾回收机制

定期运行 Codex 任务扫描漂移、更新质量等级，并发起重构 PR。类似于垃圾回收，持续小额偿还技术债务。

多 Agent 架构（Anthropic 设计）

受 GAN 启发的设计，使用生成器和评估器 Agent 创建反馈循环，推动生成器向更强的输出发展。
